# mihomo-oix

A mihomo-based proxy core with Smart Groups and oixCloud support

## Downloads

Download the latest packages from [Releases](https://github.com/vernesong/mihomo-oix/releases/tag/Pre-Alpha), choosing the file for your operating system and CPU architecture

For OpenClash and other clients, follow the client's core installation and update instructions

Each release includes `version.txt` and `checksums.txt` for version and SHA-256 verification
